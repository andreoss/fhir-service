= FHIR Service

A FHIR server. Resources are stored with every version of
themselves and answered over HTTP: read, write, history and search.

== Build

[source,shell]
----
cargo build --workspace
cargo test --workspace
cargo run --bin fhir-host
----

== Serving

[source,http]
----
GET /Patient/1
GET /Patient?name=Smith&_count=10&_sort=-_lastUpdated
GET /Patient/1/_history
----

== Layout

`core` the model and its rules, `store` the storage port, `adapter-memory`
an in-process implementation of it, `api` the HTTP surface, `host` the
binary.
